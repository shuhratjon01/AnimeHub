 AnimeHub 🎌

AnimeHub — современное десктопное приложение для поиска и просмотра информации об аниме.

Приложение создано на Python + PyQt6 и использует MyAnimeList API для получения актуальной информации об анимe

   Возможности

* 🔎 Поиск аниме
* 📚 Каталог аниме
* ⭐ Рейтинги и позиции в MAL
* 🎭 Фильтрация по жанрам
* 📺 Просмотр информации о тайтлах
* 🖼️ Загрузка и локальный кэш постеров
* 🌍 Русский, английский и японский интерфейс
* 🌑 Тёмная тема
* 💜 Киберпанк-тема
* ⚡ Анимации интерфейса
* 🎬 Информация о сезонах, эпизодах, студиях и жанрах
* 🔗 Переход к странице аниме на MyAnimeList
* ❤️ Возможность поддержать автора

   Технологии

* Python
* PyQt6
* PyQt6-WebEngine
* MyAnimeList API
* Shikimori API
* JSON

   MyAnimeList API
  
Приложение использует MyAnimeList API для получения информации об аниме.

Client ID можно указать в настройках приложения.

   Лицензия

Проект распространяется в соответствии с лицензией, указанной в репозитории.
